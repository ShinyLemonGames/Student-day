#آموزش بازی
اول از همه معذرت میخوام از PC نداران و تبریک میگم به PC داران. این بازی فقط! و فقط روی PC یا همان کامپیوتر لود میشه.
برای اینکه بتونید از بازی لذت ببرید اول فایل sb3 رو دانلود میکنید و بعدش میرید توی google و سرچ میکنید Scratch. وارد سایت Scratch.com میشید و روی گزینه Create a project میزنید. حالا باید روی Files بزنید و بعدش روی Load from your computer بزنید. اینجا میرید به بخشی که فایل رو دانلود کردید و فایل sb3 رو انتخاب میکنید. اینجا صفحه رو بزرگ میکنید و روی پرچم سبز(green flag) میزنید و بازی شروع میشه! لذت ببرید!
